#  Sensor de Proximidade com Arduino

Projeto utilizando Arduino Uno + Sensor Ultrassônico HC-SR04.

##  Componentes
- Arduino Uno
- Sensor HC-SR04
- LED
- Buzzer
- Resistor 220Ω
- Jumpers

##  Funcionamento

O sensor mede a distância e:

- > 20cm → Desligado
- 10cm a 20cm → Bip intermitente
- < 10cm → Bip contínuo

##  Objetivo

Simular um sensor de estacionamento automotivo.
